# Visual instruments and experiments

## Visual Grain / Les Lunettes de Dalí

A family of browser-based video instruments for bookmarking short regions, triggering them from controls and connecting image effects to audio or MIDI input. Later variants add layered graphics, lyric overlays and a Flask audio-analysis service. Visual Graffiti is a related interface/effects variant.

Selected Visual Grain 4, Visual Grain 6 and Visual Graffiti 7 files passed Python and JavaScript syntax checks on 27 November 2026.

**Stack:** JavaScript, Web Audio, Web MIDI, Three.js and Python/Flask.

## Terminal Diaries

A Python/PyQt6 application built around preparing diffusion-based video material before playback. Preparation and display have separate stages, with bounded generation modes, text controls and streamed FFmpeg recording.

The local project includes a PyTorch MPS diffusion path, video handling, audio analysis and recording components. All ten Python modules passed a syntax parse on 27 November 2026.

**Stack:** Python, PyQt6, PyTorch, Diffusers, OpenCV and FFmpeg.

## Terminal Universe

A Python/PySide6 prototype for developing a seed video through text and microphone input. Its modules separate the interface, media handling and local SDXL Turbo/MPS generation path.

All fourteen Python modules passed a syntax parse on 27 November 2026.

**Stack:** Python, PySide6, PyTorch, Diffusers, OpenCV and sounddevice.
