# Moorla visual tools

I build audiovisual tools for my music and video work: timing, image treatment, media preparation and export verification in one workflow.

| Project | Focus | Format |
| --- | --- | --- |
| [Moorla Kaggle](docs/moorla-kaggle.md) | Multi-source editing, scene review, guide-based color matching and Metal compositing | macOS app, version 1.1 |
| [Moorla Studio](docs/moorla-studio.md) | Music-led planning, source intervals, framing and treatment controls | macOS prototype, version 0.2 |
| [Recession Visual Synth](docs/recession-visual-synth.md) | Audio-reactive particle scenes, configurable processing and frame export | Web/Tauri prototype |
| [Visual Grain, Terminal Diaries and Terminal Universe](docs/visual-experiments.md) | Browser instruments and local diffusion-video experiments | Research prototypes |

The engineering work covers precise media handling, repeatable musical timelines, source selection, reusable preparation and controls that carry through to export. Fast draft previews and export-state previews support different stages of the creative process.

On **27 November 2026**, the shared Moorla Python suite completed **117 tests: 114 passed and 3 device-specific checks skipped**, with zero failures. Both local app binaries matched their release manifests. Recession Visual Synth also passed a fresh TypeScript/Vite production build. [Validation](docs/validation.md).

**Stack:** Swift/SwiftUI, Python, Metal, PyTorch, FFmpeg, OpenCV, React, TypeScript, Three.js and Tauri.

Documentation showcase. Application source and media remain private.
